# Roadmap

This roadmap describes possibilities, not implemented promises. Prioritize a small, testable feature at a time.

## Language
- [ ] Functions, blocks, and return values
- [ ] `if` and loop expressions/statements
- [ ] Lists, maps, and a documented standard library
- [ ] Better source locations and formatter
- [ ] Language specification and compatibility tests
- [ ] Optional bytecode/VM after profiling the interpreter

## Assistant and apps
- [ ] Provider settings UI and conversation export controls
- [ ] Optional app integrations with explicit per-action permission
- [ ] Desktop/mobile clients only after defining platform scope
- [ ] Accessibility, localization, and user-controlled data retention

## Ecosystem
- [ ] Module and package format with dependency integrity checks
- [ ] Plugin permissions and sandboxing design
- [ ] CI, release automation, and signed artifacts

Contributions should distinguish shipped behavior from proposals and include tests for user-facing changes.
